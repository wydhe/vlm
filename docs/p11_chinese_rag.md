# 中文医学问答评测：检索在这里没有帮助（负面结果）

面向国企场景补充中文评测。检索结构和英文版一一对应，只是换成中文能用的分词和模型（`rag/chinese.py`）：

| 环节 | 英文版 | 中文版 |
|---|---|---|
| 关键词检索 | BM25（按空格分词 + 词干化） | BM25（jieba 分词） |
| 向量检索 | MedCPT | bge-m3（多语言） |
| 重排 | MedCPT 交叉编码器 | bge-reranker-v2-m3 |
| 语料 | MedRAG 教材 | 华佗百科问答，36.2 万条（问题 + 答案） |

建索引：BM25 几分钟；bge-m3 编码 36.2 万条用了 20 分钟（和 GRPO 训练共用 GPU）。

评测集：MedQA-MCMLE 中文执业医师考试测试集（3,426 题，四选一）+ CMB 验证集（280 题，含 40 道多选，
多选必须全对）。生成模型 Qwen3-8B，本项目推理服务，贪心解码，每题 5 段资料。

## 结果

| 方式 | MCMLE | CMB |
|---|---|---|
| **不检索** | **0.851** | **0.689** |
| BM25 | 0.824 | 0.629 |
| bge-m3 向量 | 0.819 | 0.643 |
| 混合 + 重排 | 0.830 | 0.632 |

95% 置信区间：MCMLE 约 ±1.2 个点（下降 2.1 个点是显著的），CMB 约 ±5.4 个点（差异不显著）。

## 分析

1. **语料和题目不匹配**：华佗百科是面向大众的健康问答（"某药怎么吃""某病能治好吗"），而 MCMLE 考的是专业临床知识、
   药理和卫生法规。检索到的内容大多和题目沾边但不能回答它。
2. **模型闭卷已经很强**：Qwen3-8B 闭卷 85.1%，可补充的空间很小，无关资料带来的干扰大于帮助。
3. 几种检索方式之间：混合 + 重排在 MCMLE 上最好（0.830），但都低于不检索。

这和英文的结论一致（见 `p5_rag_agent.md` 与 `p10_pubmed_rag.md`）：**RAG 的价值取决于语料能不能覆盖题目**。
要在中文考试题上获益，需要换成中文医学教材 / 临床指南语料（例如 MedQA 原论文提供的中文教材），本项目未下载。

## 局限

- 语料只用了华佗百科问答；没有中文教材、指南类语料。
- 单次运行；没有做检索条数 k 的消融，也没有尝试"由模型决定是否检索"的 Agent 方式。
