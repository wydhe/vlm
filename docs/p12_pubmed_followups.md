# PubMed 语料下的补充实验：闭环评测与 Agent

P7 的闭环评测和 P5 的 Agent 都只用了教材语料，而 P10 已经证明 PubMedQA / BioASQ 需要 PubMed 语料。
这一步换成 PubMed 语料把这两个实验重跑一遍（`scripts/run_pubmed_followups.sh`）。

代码改动：新增 `rag/search.py`，按语料名（`textbooks` / `pubmed`）加载检索器，统一返回 `{id, title, content}`；
`agent/grounded_qa.py` 和 `agent/medical_agent.py` 加了 `--corpus` 参数。闭环评测的检索结果按 语料/k/seed 缓存，4 个模型共用。

## 1. 闭环评测：Qwen3-1.7B 原始模型 vs GRPO（3 个种子的最好检查点）

MIRAGE 的 PubMedQA（500）+ BioASQ（618），每题 4 篇文档。策略：closed 闭卷；rag 只看资料，拒答记错；rag+fb 资料不足时改闭卷作答。

| 条件 | 指标 | 原始模型 | GRPO（3 个种子） |
|---|---|---|---|
| **BioASQ，PubMed 检索** | 闭卷 | 0.487 | 0.600 ± 0.041 |
| | 只用资料 | 0.542 | **0.818 ± 0.016** |
| | 资料不足时闭卷兜底 | 0.706 | **0.846 ± 0.011** |
| PubMedQA，PubMed 检索 | 只用资料 | 0.446 | 0.691 ± 0.007 |
| | 资料不足时闭卷兜底 | 0.528 | 0.699 ± 0.008 |
| PubMedQA，原始摘要 + 3 篇 PubMed 干扰摘要 | 只用资料 | 0.382 | 0.624 ± 0.014 |
| | **引用准确率** | 0.314 | **0.604 ± 0.026** |

- **BioASQ 是最有说服力的结果**：1.7B 的 GRPO 模型在 PubMed 检索下达到 0.846，接近 Qwen3-8B 检索后的 0.871（P10），
  高于 Qwen3-8B 闭卷的 0.794。原始 1.7B 模型的拒答本来就不多，提升主要来自"读懂资料后答对"（只用资料：0.542 → 0.818）。
- **难干扰下的引用**：干扰文档从教材段落（P7）换成内容相近的 PubMed 摘要后，原始模型的引用准确率从 0.650 掉到 0.314；
  GRPO 模型是 0.604。GRPO 训练用的正是 BM25 找出的相似摘要做干扰，这个条件和训练分布最接近。
- 闭卷准确率：原始模型这次是 0.278，P7 是 0.298。两次都是贪心解码，但并发下批次组成不同，bf16 数值有细微差异，
  会改变个别题的输出。这类差别在 ±2 个点以内，下结论时不应依赖。

### PubMedQA 的检索结果含有答案（重要）

PubMedQA 检索条件（0.691）反而高于"保证给原始摘要"的条件（0.624）。原因是：PubMedQA 的设定只给摘要的背景和方法部分，
**结论段（long_answer）被刻意拿掉**；而 PubMed 语料收录的是完整摘要。抽查前 200 题，**96% 的检索结果里包含该题原文的结论段**，
相当于把答案也检索了出来。因此 **PubMedQA 上所有"PubMed 检索"的数字（含 P10 的 0.558 → 0.734）都高估了检索的真实价值**，
只能说明"检索系统找得到原文"（召回率 0.97）。BioASQ 不存在这个问题，结论以 BioASQ 为准。

## 2. Agentic RAG：教材 vs PubMed（Qwen3-8B，同一批 1,000 题）

| | MedQA | MedMCQA | PubMedQA* | BioASQ | MMLU-Med | 平均 | 每题检索次数 | 前缀缓存命中率 |
|---|---|---|---|---|---|---|---|---|
| 不检索 | 0.590 | 0.605 | 0.875 | 0.810 | 0.765 | 0.729 | 0 | — |
| 单次检索（教材，混合 + 重排） | 0.560 | 0.595 | 0.495 | 0.700 | 0.785 | 0.627 | 1 | — |
| Agent（教材） | 0.620 | 0.585 | 0.645 | 0.755 | 0.810 | 0.683 | 0.93 | 21% |
| **Agent（PubMed）** | 0.625 | 0.570 | 0.840 | **0.865** | 0.790 | **0.738** | 0.77 | 12% |

\* 题目按"每个数据集取前 200 题"选取，**MIRAGE 的 PubMedQA 前 200 题标签全部是 yes**（全集 500 题是 yes 276 / no 169 / maybe 55），
这一列偏向"倾向回答 yes"的方法，不能单独解读；同时还受上一节的答案泄漏影响。其他数据集前 200 题的标签分布正常。

- Agent 换成 PubMed 语料后平均 0.738，**第一次超过了不检索（0.729）**，但只高 0.9 个点。1,000 题的 95% 置信区间约 ±2.7 个点，
  差异不显著。
- BioASQ 上 +5.5 个点（0.810 → 0.865），和 P10 单次检索的结论一致。
- 模型会按工具描述调整检索行为：工具写成"检索科研文献摘要"后，MMLU 每题的检索次数从 0.86 降到 0.50，
  MedMCQA 从 0.96 降到 0.67，不检索的题占 24%。检索变少，前缀缓存的命中率也随之从 21% 降到 12%。

## 局限

- Agent 的抽样方式（前 N 题）有偏，PubMedQA 一列尤其明显；应改为随机抽样后重跑全部对比，本轮未做。
- 闭环评测里，PubMedQA 的检索条件受答案泄漏影响；较干净的对比只有 BioASQ。
