# P5：医疗 RAG 与 Agentic RAG

生成模型：Qwen3-8B（关闭 thinking，贪心），由本项目 nano-vllm 引擎的 OpenAI 兼容服务提供。
语料：MedRAG Textbooks（18 本医学教材，125,847 个片段）。评测：MIRAGE。

## 检索栈（`rag/retrievers.py`）

| 阶段 | 实现 |
|---|---|
| 稀疏 | BM25（bm25s，Snowball 词干 + 停用词），索引 14 s |
| 稠密 | MedCPT Query / Article 双编码器（NCBI，基于 PubMed 检索日志训练），CLS + 内积，GPU 精确检索；12.6 万片段编码 93 s |
| 融合 | RRF（c = 60），各取 top-50 候选 |
| 重排 | MedCPT Cross-Encoder，top-50 → top-k |

## 单次 RAG（`rag/eval_mirage.py`，k = 5，每数据集最多 1000 题，共 4,118 题）

| 模式 | MedQA (1000) | MedMCQA (1000) | PubMedQA (500) | BioASQ (618) | MMLU-Med (1000) | 平均 |
|---|---|---|---|---|---|---|
| 不检索 | 0.630 | **0.584** | **0.560** | **0.796** | **0.775** | **0.669** |
| BM25 | 0.617 | 0.523 | 0.440 | 0.633 | 0.746 | 0.592 |
| MedCPT 稠密 | 0.614 | 0.546 | 0.426 | 0.652 | 0.755 | 0.599 |
| 混合（RRF） | 0.620 | 0.541 | 0.428 | 0.633 | 0.766 | 0.598 |
| 混合 + 重排 | **0.643** | 0.561 | 0.420 | 0.660 | 0.768 | 0.610 |

95% 置信区间：n=1000 约 ±3 个百分点，n=500 约 ±4.4。

**结论（负面结果，如实记录）**

- 检索方式之间：混合 + 重排 > 稠密 ≈ 混合 > BM25，重排在 4 个数据集上优于未重排的混合检索。
- 但**以教材为语料时，强制检索整体降低准确率**（0.669 → 0.610）。PubMedQA / BioASQ 降幅最大：它们考的是科研文献结论，
  教材中没有对应内容，检索到的无关段落干扰了模型——与 MedRAG 论文一致（这两个数据集需要 PubMed 语料，约 70 GB，未下载）。
- 只有 MedQA（教材覆盖的临床知识）上 +1.3 个点，不显著。
- 带文档时未解析（未输出选项字母）的回答由 5 增至 65~93，说明长上下文下格式遵循变差。

## Agentic RAG（`agent/medical_agent.py`）

- Qwen3 原生函数调用：工具 `search_medical_kb(query)` → 混合 + 重排 top-3；最多 3 次检索，最终回复 `Answer: X`。
- 服务端新增：聊天接口 `tools` 透传给 chat template；`/metrics` 返回累计 prompt token 与前缀缓存命中 token。
- 用完检索预算后不移除工具定义（否则 system prompt 变化导致前缀缓存失效），而是由工具返回"已达上限"。

同一批 1000 题（每数据集 200 题，取自上面的同一抽样）：

| 方法 | MedQA | MedMCQA | PubMedQA | BioASQ | MMLU | 平均 |
|---|---|---|---|---|---|---|
| 不检索 | 0.590 | **0.605** | **0.875** | **0.810** | 0.765 | **0.729** |
| 单次 RAG（混合 + 重排） | 0.560 | 0.595 | 0.495 | 0.700 | 0.785 | 0.627 |
| **Agent** | **0.620** | 0.585 | 0.645 | 0.755 | **0.810** | 0.683 |

| Agent 统计 | 值 |
|---|---|
| 平均工具调用 / 题 | 0.93（9.8% 的题未检索） |
| 平均轮数 | 1.93 |
| 单题延迟中位数（64 并发） | 4.9 s |
| 1000 题总耗时 | 116 s |
| 前缀缓存命中率 | **21.1%**（120.8 万 prompt token 中 25.5 万免算） |

**结论**

- Agent 比强制单次 RAG **+5.6 个点**；在教材覆盖的 MedQA / MMLU 上还超过了不检索（+3.0 / +4.5，n=200 时 ±6.5，不显著）。
- 但模型几乎总是检索（90%），在语料不覆盖的 PubMedQA 上仍被拖累。"何时该检索、文档无关时如何作答"正是 P6 GRPO 的训练目标。
- 前缀缓存命中率受 256 token 块粒度限制：首轮 prompt（system + tools + 题目）约 500 token，只能复用 1 个整块。

## 局限

- 未使用 PubMed / StatPearls 语料；PubMedQA / BioASQ 的检索结论不能外推到完整 MedRAG 配置。
- Agent 每数据集 200 题，统计功效有限；单次运行。
