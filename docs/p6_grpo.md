# P6：GRPO 对齐——有据作答、正确引用、无据拒答

## 任务（`align/task.py`，全部可自动判定，无需奖励模型或 LLM 评委）

- 每题给 4 篇 PubMed 摘要：题目自身的摘要（gold）+ 3 篇 BM25 最相近的干扰摘要，随机打乱。
- 25% 的样本把 gold 换成另一篇干扰摘要 → 正确回答是 `insufficient`。
- 输出格式：`Reasoning: … / Citation: [n] | none / Answer: yes | no | maybe | insufficient`。
- 奖励 = 格式 0.1 + 答案 1.0 + 引用 0.5（可答题须恰好引用 gold；不可答题须 `Citation: none`）；
  可答题回答 `insufficient` 得不到答案分——过度拒答被隐式惩罚。
- 数据：训练取自 `pqa_artificial`（4,000 条，yes/no **按标签平衡**——原始分布 yes:no ≈ 15:1，
  不平衡时策略可以靠"永远答 yes"拿奖励）；评测取自 `pqa_labeled`（500 条，含 maybe，与训练不重叠）。

## 训练器（`align/grpo.py`，手写，单卡）

```
P=16 题 ──► nano-vllm 引擎：每题 G=8 条采样（T=1.0, ≤256 token）
   │                               ▲
   ▼                               │ 原地权重同步 + 前缀缓存清空
可验证奖励 ──► 组内归一化优势 ──► 策略梯度 + KL(k3, β=0.04) ──► AdamW(lr 1e-6)
```

| 设计点 | 做法 |
|---|---|
| Rollout | 本项目推理引擎与训练同进程同卡；每步后 `load_weights` 原地拷贝权重（CUDA Graph 指针不变） |
| **前缀缓存失效** | 所有样本共享 system prompt，若不清空，新一步 rollout 会复用旧策略算出的 KV，**静默地变成 off-policy**；每次同步后 `reset_prefix_cache()` |
| 显存规划 | 策略/参考模型、梯度、AdamW 状态在引擎初始化**之前**分配（用一次零梯度 step 预分配优化器状态），引擎按剩余显存划分 KV |
| 精度 | 策略保留 fp32 主权重 + bf16 autocast；lr 1e-6 的更新在纯 bf16 下大多会被舍入 |
| 优势 | `(r - mean) / (std + 1e-4)`；组内奖励全相同的组无梯度信号，直接跳过 |
| 损失 | 每批只更新一次（ratio ≡ 1，clip 不生效）：`-A·logp + β·KL_k3`，序列内 token 平均、序列间平均 |
| 显存优化 | LM head 只在 completion 位置计算，避免 [B, T, vocab] 的 logits 张量；gradient checkpointing |

## 结果（Qwen3-1.7B，150 步，单种子，评测 500 条贪心解码）

| 指标 | step 0 | 25 | 50 | 75 | 100 | 125 | **150（最终）** |
|---|---|---|---|---|---|---|---|
| 格式正确率 | 0.920 | 0.992 | 0.984 | 0.996 | 0.996 | 0.992 | **0.994** |
| 答案准确率（可答题） | 0.439 | 0.532 | 0.615 | 0.636 | 0.661 | 0.579 | **0.633** |
| 引用准确率（可答题） | 0.711 | 0.858 | 0.889 | 0.891 | 0.912 | 0.840 | **0.897** |
| 过度拒答（可答题答 insufficient，↓） | 0.134 | 0.109 | 0.090 | 0.090 | 0.059 | 0.124 | **0.085** |
| 拒答召回（不可答题答 insufficient） | 0.982 | 0.973 | 0.982 | 0.982 | 0.947 | 0.965 | **0.982** |
| 平均奖励 | 1.040 | 1.173 | 1.251 | 1.270 | 1.289 | 1.201 | **1.269** |

**最终相对初始**：答案准确率 +19.4 个点，引用准确率 +18.6，过度拒答 −4.9，拒答召回保持 0.982。

训练动态：

| 区间 | 平均奖励 | KL | 回复长度 | 无信号组 / 16 | rollout / 训练 每步 |
|---|---|---|---|---|---|
| 1–25 | 1.063 | 0.016 | 106 | 8.1 | 4.3 s / 12.6 s |
| 51–75 | 1.236 | 0.085 | 126 | 10.2 | 4.7 s / 9.5 s |
| 126–150 | 1.258 | 0.086 | 110 | 9.8 | 4.3 s / 10.0 s |

总训练时间 36 分钟（单卡 A800）。

## 分析与局限

- 参照：可答题中 yes 占 53%，"永远答 yes" 可得 0.532；训练前（0.439）低于该基线，训练后（0.633）明显超过。
- 训练集来自 `pqa_artificial`，**没有 maybe 标签**，而评测中 maybe 占可答题 11%，这部分基本学不到，是答案准确率的上限因素之一。
- step 125 出现一次回落后恢复，最好点在 step 100；只保存了最终权重，且只有一个随机种子——结论的稳健性需要多种子验证。
- 每步约 60% 的组奖励无方差、被跳过：提高组大小或按难度采样（DAPO 的 dynamic sampling）可提高样本效率。
- 评测 n=500（可答 387 / 不可答 113）：答案准确率 95% 置信区间约 ±4.8 个点，引用准确率约 ±3.1。
